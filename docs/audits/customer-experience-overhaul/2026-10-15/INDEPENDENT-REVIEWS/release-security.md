### [P2, Closed After Recheck] Funnel Pixel helper bypassed the disabled advertising boundary

- Original location: src/lib/funnel/events.ts:28-31. `pixelEvent` called `window.fbq('track', ...)` directly instead of the newly disabled advertising helper. Real callers are src/app/q/[slug]/_Funnel.tsx:280, :439, :718 and :760 (reveal, checkout and contact actions).
- Independent local reproduction with a retained legacy SDK represented by a window.fbq spy: invoking the actual helper produces one tracking call before any analytics choice, one after explicit withdrawal, and one after usage-only opt-in. No external network or real advertising event was sent. The worker's 28 passing analytics tests cover fbqTrack being disabled and SDK revocation, but do not exercise this second real funnel helper.
- Scope: the direct Pixel helper predates this overhaul; the regression is that the new advertised default-deny/advertising-disabled boundary does not cover this existing caller when a legacy global is present. The new Meta component correctly loads no advertising SDK on a fresh document, so this is specifically the retained-global path, not evidence of new Meta downloads in a fresh browser. Do not rely on a vendor SDK continuing to honor an earlier revoke call when the product can avoid invoking advertising capture altogether.
- Acceptance: route all four funnel actions through the disabled advertising helper, or make pixelEvent explicitly inert for this release. Add an SDK-spy regression proving zero advertising track calls before choice, after withdrawal and after usage-only opt-in, including an already-present global. Keep first-party optional events independently consent-gated. No product edits made by this reviewer.
- Closure at 01:04:21 Asia/Dubai: the actual helper now imports fbqTrack at line 4 and delegates at lines 29-30. Independently reran funnelPixelPrivacy (1 test covering three event types across pre-choice, usage opt-in and withdrawal), analyticsConsent (28 passing unit tests, one browser fixture skipped), and publicNatalTransport (7): 36 passed, one skipped. The retained SDK receives zero calls. A final source search finds no other direct advertising capture in src; only the Meta component's consent-revoke path accesses the legacy global. The unit-test skip is the optional browser fixture, not a skipped failing assertion; the primary owns browser evidence.
